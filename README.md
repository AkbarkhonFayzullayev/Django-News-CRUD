# Django News Website 📰

A dynamic news website developed using Python and Django.

## Features

- Browse the latest news and articles.
- View news by categories.
- Organized news management.
- User-friendly interface.
- Dynamic content powered by Django.

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap

## Installation

1. Clone the repository:

```bash
git clone https://github.com/AkbarkhonFayzullayev/Django-News-CRUD
```

2. Navigate to the project directory:

```bash
cd Django-News-CRUD
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the virtual environment:

```bash
source venv/bin/activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run migrations:

```bash
python manage.py migrate
```

7. Start the development server:

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
